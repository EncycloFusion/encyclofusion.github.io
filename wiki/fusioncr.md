**Clickteam FusionCR**, where "**CR**" stands for **Compact Reactor**, is an online visual programming
tool by [Clickteam] and an entry of the Click line of products that enables the use of the event editor
system of game creation through almost any browser with apps for mobile devices coming soon. FusionCR is
based on the backbone of [Multimedia Fusion Express] and [The Games Factory], but modernized with new
features and designed for HTML5. It is currently in a Closed Beta which can be accessed by subscribers to
Clickteam's Patreon page.

FusionCR is not meant to be a direct successor to [Clickteam Fusion 2.5], it is intended to be
an entry level light development tool primarily for hobbyists, casual game developers, and educators,
similarly to The Games Factory but for web browsers and mobile devices. Applications created in FusionCR can
be exported as .GAM files which can be opened in Fusion 2.5, or as .FusionCR files specifically for FusionCR.
The .GAM format FusionCR exports is similar to the one used by The Games Factory, but FusionCR's .GAM files
are incompatible with TGF and C&C because they store expressions in a CF2.5 format rather than the one TGF uses.

Games made with FusionCR are designed to be played within FusionCR itself, through the **FusionCR community** which
is the primary method of sharing FusionCR games for others to play, although they can be exported to Fusion 2.5
as well. Once released, FusionCR itself will be free to use, but for monetization it will have an in-app currency
called **Tritium** which can be used to buy premium tutorials, exclusive premium games and more compile time.
